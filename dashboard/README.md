# B2W: локальный монитор обучения

Запуск из корня репозитория:

```powershell
& ./scripts/run_local.ps1 dashboard/server.py
```

Открыть `http://127.0.0.1:8765`. Сервер слушает только loopback; порт можно
переопределить аргументом `--port`. Для остановки foreground-запуска — Ctrl+C.

Сайт читает `logs/rsl_rl/*/*/continuation_manifest.json`, `progress.json` и
TensorBoard scalar events. Доступны все существующие локальные runs с manifest
и event-файлами. Новые события обновляются каждые 10 секунд; запись event writer
может отставать от `progress.json`. Все scalar points сохраняются, линия EMA
рисуется поверх исходных значений. Hover показывает исходное значение.

Процесс не импортирует Torch, не запускает Isaac и не меняет обучение или логи.
Нет API управления jobs или чтения произвольных файлов. Checkpoints доступны
как список метаданных, без загрузки weights в память. Статус «Нет свежих данных»
означает отсутствие новых updates более 90 секунд; он не доказывает остановку
процесса. ETA рассчитывается по среднему времени выполненных updates.

Ход проверки 23999 читается из `logs/fullcycle23999_validation_20260927/evaluation_progress.json`.
После завершения и проверки traces сайт использует
`docs/results/evidence/fullcycle_23999_20260927/summary.json`: свежие 21999/23999,
а также сохранённый контроль 19999. Контроль выбирается в разделе теста.
До готовности этого файла показывается предыдущая проверка 19999/21999.
Таблица содержит все 234 сценария, отдельные показатели unsafe и физического
stair-stop покрытия. Новые evaluations сайт не запускает.

Frontend: статические HTML/CSS/JS в `dist/`, без внешних CDN и сборки.
Backend: стандартная библиотека Python и уже установленный TensorBoard.
Live данные не копируются в Git. Сайт локальный, внешняя публикация не нужна.
