## Проверки и оценка

18 CPU tests прошли; оба режима прошли GPU smoke 16 сред × 2 updates с exit 0
и finite checkpoint/optimizer. Диагностический replay: exit 0, 4400 physics steps.
Длительный предыдущий режим 2×4096 завершён: 1223 resource samples, telemetry
errors 0, peak VRAM 9631 MiB, минимальный запас 21,58%, максимум 53 °C.

Координатор ограничивает время парного training двумя часами, проверяет finite
артефакты и запас VRAM ≥15%, экспортирует оба checkpoint с parity проверкой.
После training выполняются последовательные flat100 evaluations:
control и mix на eval seeds 20260917 и 20260918; исходный seed 44 и reference
на 20260918. Первый набор уже диагностический, второй заранее зафиксирован
для этого сравнения; финальная приёмка потребует новых данных.

Вариант считаем перспективным, только если на обоих наборах оба направления
yaw улучшают pooled yaw RMS минимум на 10% относительно control, число эпизодов
без отказа не уменьшается, а pooled RMS каждого не-yaw сценария остаётся в
порогах 0,2 / 0,2 / 0,25. Иначе результат отрицательный или неопределённый.
Автоматического перехода к Rough нет.
