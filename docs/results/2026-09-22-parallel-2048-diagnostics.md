22 сентября 2026. На локальной RTX 4080 Laptop выполнены три пары PPO запусков: в каждой паре training seeds 54 и 55 работали одновременно, каждый с 2048 средами. Во время полного обучения `nvidia-smi` показывал около 11.2 из 12.3 ГБ VRAM (снимок, не peak). Два коротких smoke 2048×1 с reset probes прошли до полного запуска. Все шесть полных run завершились без ошибки памяти.

Контроль — v3, плавное торможение с 0.7 до 0.25 м/с на последних 1.2 м. `passage_bonus` меняет только вес награды за первый безопасный проход с 0 на 25. `late_brake` меняет только дистанцию торможения с 1.2 на 0.8 м. Всё остальное совпадает: один rough parent `model_349.pt` (SHA-256 `916bf5c5b4e5ca43ecfacd4bde6c5a92b164b9c0a6d5c9257a6c7ed68662febf`), actor 57→16, 30/30% подъём/спуск, 10% landing starts, 15% flat, 10% random rough, 5% inverse rough, fixed std 0.1 и LR 1e-4. Каждый run — 2048×50×24 = 2 457 600 transitions; всего 14 745 600. Финальный checkpoint выбирался заранее: `model_398.pt`, без выбора максимального training reward. Из-за 50 против 25 PPO updates результаты по качеству нельзя приписать только переходу с 4096 на 2048 сред.

## Rough regression

Level 9, 512 сред × 1000 policy steps, `--reset-tilt-limit 0.3`, mesh seeds 2006 и 2005. Формат ячейки: безопасно всего / безопасно на обратных ступенях. Требование inverse ≥97/102 на каждом mesh seed и ≥95% для каждого семейства. Tracking каждого run находится в пределах 10% от parent по компонентам; остальные семейства rough также прошли порог 95%. Seed 2005/2006 остаются development regression, не независимым финальным набором.

## Открытый полный цикл: 14/32 см

Диагностическая строка с открытым seed 3001, отдельно подъём/спуск: 64 среды × 800 шагов, protocol v3. Ячейки показывают безопасные полные циклы из 64. Parent оценен при том же профиле команды: для 1.2 м использованы сохранённые v3 JSON, для 0.8 м выполнена новая оценка. Эти две строки не заменяют полную открытую suite и не служат приемкой.

У `passage_bonus/55` лучший результат цикла на этой геометрии, но rough inverse 95/102 на обоих mesh seeds. У `late_brake` виден выигрыш на подъёме относительно parent с тем же профилем (41→45/44), но спуск меняется разнонаправленно (49→46/52). У контроля цикл хуже parent на обоих training seeds. Основные потери остаются после прохода: например, `control/55` на подъёме имеет 51/64 безопасных проходов, но 38/64 полных циклов, 9 отказов остановки и 11 незавершённых попыток; `late_brake/55` — 55 проходов, 44 цикла и 10 отказов остановки. Это указывает, где собирать дополнительную диагностику, но не доказывает причину отказа.

**Решение:** модели не принимать и не дообучать по одному удачному seed или одной открытой геометрии. Control и late brake прошли development rough regression на обоих training seeds, но диагностические лестничные циклы недостаточны для вывода о полном открытом gate; passage bonus не прошёл rough. Основным остаётся rough parent. Если продолжать эту линию, следующая зафиксированная гипотеза должна адресовать остановку/повторный старт с проверкой train/eval на границе и без утраты rough поведения. Закрытые stair seeds 4101–4104, новая финальная rough suite, export parity и sim2sim не запускались.
