# 19999 → 20500: промежуточная проверка локального дообучения

26 сентября 2026. Проверен заранее выбранный последний сохранённый checkpoint
на момент начала работы — **20500, 501 дополнительное PPO-обновление**.
Позднее появившиеся checkpoint'ы в это сравнение не подменялись.

**Есть прогресс и регресс. Условие сохранения всех освоенных строк пока не выполнено.**
Обучение продолжалось параллельно; параметры run по результатам screen не менялись.

## Результат

Выполнены два новых deterministic Isaac Flat screen: исходная 19999 и кандидат
20500, каждый **36 сценариев × 32 reset seeds 8201–8232**, итого 2304 эпизода.
Использованы одинаковые physics, порядок эпизодов, schedules, observations и gates.

| Метрика | Исходная 19999 | Кандидат 20500 |
|---|---:|---:|
| Полный успех | 716/1152 (62.15%) | 766/1152 (66.49%) |
| Успешный непрерывный ноль | 1079/1152 | 1151/1152 |
| Unsafe | 3 | 0 |
| Флаги нарушения moving-window transitions | 312 | 91 |
| Флаги tracking failure | 213 | 298 |
| Флаги standstill failure | 70 | 1 |

Флаги могут пересекаться в одном эпизоде. У 19999 три unsafe не дошли до полного
нулевого сегмента; они остаются в знаменателе 1152 и не считаются успешным нулём.

Свежая 19999 воспроизвела retained screen: **0 изменений outcome и 0 изменений
набора failure flags** во всех 1152 эпизодах, те же 716 полных успехов и три
нарушения hard joint position. Это не сравнение разных версий протокола.

У кандидата **8 строк улучшились, 7 ухудшились, 21 не изменилась** по full pass.
Суммарное улучшение +50 эпизодов (+4.34 процентного пункта) не отменяет регрессы.

## Где есть прогресс

- Непрерывный ноль улучшился на 72 эпизода; после всех yaw и turning сценариев
  теперь 32/32. Единственный отказ нуля — `vy=-1.0`, seed 8213.
- Чистые yaw −0.7: 0→31/32; +0.7: 14→30/32; −1.0: 0→32/32; +1.0: 1→30/32.
- На yaw −0.7 число завершённых эпизодов с нарушением moving RMSE по vy
  уменьшилось 32→1; на yaw +0.7 — 12→0. Побочный снос заметно уменьшился.
- Turning при движении вперёд: 30→32/32 и 29→32/32.
- Сохранились 32/32 по всем шести продольным точкам ±0.3/0.5/0.7,
  боковым ±0.5/0.7, longitudinal transitions, stand и двум исходным
  диагоналям 32/32.
- В этом screen нет unsafe у кандидата. Максимум wheel speed снизился
  38.55→37.79 rad/s, максимум per-episode wheel saturation fraction
  7.18%→4.68%, максимальная непрерывная saturation 0.20→0.14 s.
  Эти значения — simulator telemetry, не аппаратная qualification.

## Где есть регресс

- Чистый yaw −0.5: **6→0/32**, +0.5: **21→0/32**.
  Медианы фактического yaw уменьшились −0.432→−0.363 и +0.410→+0.349 rad/s.
  У кандидата moving RMSE проходит, но отклик составляет лишь 72.6% и 69.8%
  команды при требовании ≥80%. Остановка исправилась, недостаточный отклик
  остаётся самостоятельным отказом.
- Задний ход с yaw −0.5: **27→20/32**; задний ход с yaw +0.5: **28→4/32**.
  Основная измеренная причина — снижение angular response. Для положительного
  yaw медиана response ratio 92.2%→75.9%.
- `vy=-1.0`: **32→29/32**. Это единственная потерянная исходная строка 32/32:
  два transition failures и один standstill failure.
- Диагональ (-0.5,+0.5,0): **31→29/32**; transitions_vy: **3→0/32**.
- Малые yaw ±0.3 и боковые ±0.3 по-прежнему имеют 0/32.
  Для yaw +0.3 фактическая скорость даже снизилась +0.170→+0.143 rad/s;
  малые команды пока нельзя считать исправленными.

Снижение yaw response — установленное поведение. Причину в конкретной награде
или изменении распределения этот единственный промежуточный screen не доказывает.
