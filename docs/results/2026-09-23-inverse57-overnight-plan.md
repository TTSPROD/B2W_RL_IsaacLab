- Parent: upstream model_10000.pt, SHA-256 `611dba2dfbb53f828c2a6e005a44c612970a5ca42e8f9261bb22b5f9c4659caa`.
- Переносятся actor, critic, exploration std и Adam; равенство model state проверяется на всех четырёх rank. Learning rate принудительно 1e-4, schedule fixed.
- 4096 сред суммарно, 1024 на rank, rollout 24, базовый seed54 плюс rank.

## Правила отбора

Парный baseline пересчитывается на сервере: аппаратная платформа отличается от предыдущего Windows evaluator. Девять сценариев на модель: flat128×1000, rough2009/2010 по512×1000 на level9, шесть stair-v3 development по128×900. Evaluators скопированы без изменений; Linux bootstrap добавляет только pinned URDF compatibility и локальные пути assets.

Допуск кандидата к выбору: flat128/128, rough safe не ниже серверного parent, лестничные циклы не ниже parent, unsafe не выше parent. Среди допущенных — rough gate, минимум inverse, сумма inverse, rough safe, худшая stair-строка, сумма циклов и unsafe.

Продление пилота после1000 updates допускается, если хотя бы одна проверка улучшила minimum inverse или inverse total минимум на2, при rough деградации не более3, потере циклов не более8 и росте unsafe не более4. Эти допуски служат только продолжению исследования; финальный отбор строже.

Две подряд проверки с flat failure, rough падением более10, потерей более24 циклов или ростом unsafe более12 останавливают run. После2000 updates четыре проверки без нового выбранного кандидата означают plateau. Если лучший кандидат не превзошёл parent по правилам — возвращается исходный parent с явной пометкой, а не новая принятая модель.

## Validation и доставка

Заранее зафиксированы новые seeds: flat51005; rough52009/52010; stairs53001/53003/53002 на прежних геометриях. Их не используют для выбора checkpoint. Закрытые4101–4104 не запускаются. В конце сравниваются parent и выбранная модель; принятие требует rough gate и сохранения навыка относительно parent. Release gate дополнительно требует95% цикла в каждой stair-строке. Один seed обучения и новые mesh/reset seeds не доказывают перенос на новые геометрии или реального робота.

Сервер формирует `delivery.tar.gz`: checkpoint, provenance, отчёт и сырые оценки. Локальный `scripts/server_inverse57/collect.py` проверяет SHA, распаковывает в `artifacts/upstream/inverse57_4gpu_20260923/` и запускает девять локальных проверок новой выбранной модели. Если выбран неизменный parent, его существующие локальные проверки не дублируются. Collector временно удерживает Windows от автоматического idle-sleep, не меняя постоянный план питания; ручной сон/выключение прерывают локальную доставку, но не серверный эксперимент.

Часовой heartbeat `b2w-inverse57` отключён (PAUSED) по последующему указанию пользователя. Эксперимент и доставка выполняются отдельными процессами; открытый чат не требуется. Независимый серверный watchdog останавливает только этот контейнер перед исходным 15-часовым дедлайном даже при зависании управляющего процесса.
