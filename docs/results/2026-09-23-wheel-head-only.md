# Stair 57→16: wheel-head-only fine-tuning

23 сентября 2026. Протокол фиксируется до обучения. Только локальная симуляция; сервер не используется.

## Гипотеза

Внешнее обнуление четырёх wheel-action в hold-фазе заметно снизило stop failures, но добавило по одному unsafe на обоих control57 parents. Вместо скачка в runtime адаптируются только четыре wheel-output строки последнего actor-слоя. Все скрытые actor-слои и 12 leg-output строк заморожены; critic обучается штатно. Actor ABI и наблюдения неизменны: строго 57→16.

Parents — control57 seeds 54/55 `model_398.pt`. Fresh optimizer, стандартная смесь 35% up / 35% down / 15% flat / 10% random rough / 5% inverse, landing tiles 10%, brake/cycle v3 без изменений. Единственное изменение reward — уже реализованный плотный `stop_speed` с весом 1.0. Бюджет 2048 сред × 25 обновлений; заранее выбран `model_422.pt`.

## Ворота

1. Smoke: actor 57→16; reset probes безопасны; manifest подтверждает 12 замороженных leg rows и 4 обучаемых wheel rows.
2. После обучения проверить, что все actor tensors кроме последних четырёх строк `actor.6.weight/bias` бит-в-бит совпадают с parent.
3. Rough 2009/2010: каждое семейство ≥95%, inverse ≥97/102; flat1005 — 128/128.
4. Открытая stair suite только после rough/flat. Каждый seed должен улучшить свой control57 по полному циклу без роста unsafe; закрытые seeds не использовать.
